## Agent

Mostly—but the new Perlin fog is not yet verified on a physical phone.

- The layout, controls, pause behavior, audio, and earlier animations were previously tested on an iPhone.
- `feTurbulence` is broadly supported on mobile browsers and has been widely available since 2015.
- The concern is `feDisplacementMap` applied through a CSS SVG filter. WebKit has had rendering and performance bugs around this combination, including recent Safari regressions.
- If the filter is unsupported, the underlying moving fog shapes should remain visible, but they may lose their organic noise distortion.
- Full-screen noise filtering could also run more slowly on older phones.

So: it should work, but we need to open the deployed HTTPS build on your phone and check the reveal, animation smoothness, Pause, and whether Safari reloads or crashes. I wouldn’t mark the Perlin version mobile-approved until that test passes.
